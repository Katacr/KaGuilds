# Custom Menus

KaGuilds provides a configurable GUI menu system. Menu files are stored in `plugins/KaGuilds/gui/`; keep a backup before editing them.

- [Layout and Refresh](layout.md)
- [Icons and Dynamic Lists](display.md)
- [Click Actions](actions.md)

Reopen a menu to load its updated configuration. Back up customized files before updating the plugin or extracting bundled menus.
